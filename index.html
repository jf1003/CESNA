Encodage des points

Clic sur un AA : ✓ acquis → ✕ non acquis (rouge en 2ᵉ session) → D dispensé → vide. Tous les AA verts ou dispensés (D) : vous encodez la note (50 à 100). Un AA non acquis = Ajourné. En 2ᵉ session, les AA déjà acquis restent verts d'office. Réussi en 1ʳᵉ session : 2ᵉ session grisée. Étudiant en abandon : rouge « Refus ». Clic sur « AA n » (en-tête) = acquis pour toutes les cases vides · Entrée = note suivante.
